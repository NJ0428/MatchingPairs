<h1 style="text-align: center;">🎮MatchingPairs 게임 설명</h1>
<p>MatchingPairs는 기억력과 집중력을 테스트하는 <strong>짝 맞추기 퍼즐 게임</strong>입니다. 보드 위에 다양한 카드나 아이템이 뒷면으로 배열되어 있으며, 같은 그림이나 패턴을 가진 쌍을 찾아 짝을 맞추는 게임입니다. 이 게임은 전통적인 <strong>카드 뒤집기 게임(Memory Game)</strong> 또는 <strong>페어 매칭 게임</strong>으로도 잘 알려져 있습니다.</p>

<div style="margin-bottom: 20px;">
  <h2 style="color: #007bff;">게임 설명 및 규칙</h2>

  <ul style="margin-left: 20px;">
    <li>16장의 카드가 뒷면으로 있습니다.</li>
    <li>각 카드에는 다양한 이미지가 있으며, 동일한 쌍의 이미지가 한 세트로 존재합니다.</li>
  </ul>
</div>

<div style="margin-bottom: 20px;">
  <h3 style="margin-top: 10px;">게임 진행 방법</h3>
  <ul style="margin-left: 20px;">
    <li><strong>한 번에 두 장의 카드</strong>를 선택해 뒤집습니다.</li>
    <li>두 카드의 이미지가 일치하면 해당 카드는 짝으로 인정되어 보드에서 제거되거나 고정됩니다.</li>
    <li>두 카드의 이미지가 다르면 다시 뒷면으로 뒤집히며, 다음 턴으로 넘어갑니다.</li>
  </ul>
</div>

<div style="margin-bottom: 20px;">
  <h3 style="margin-top: 10px;">게임 목표</h3>
  <ul style="margin-left: 20px;">
    <li>가능한 적은 횟수로 <strong>모든 짝을 맞추는 것</strong>이 목표입니다.</li>
  </ul>
</div>
